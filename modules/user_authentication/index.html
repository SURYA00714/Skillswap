How to run with VS Code Live Server or static server

Right-click on modules/user_authentication/index.html (or any of the individual html files) and choose "Open with Live Server", or run in terminal: 

# Option A: Python Built-in Server
cd modules/user_authentication && python3 -m http.server 5500

# Option B: Node http-server or npx serve
npx serve modules/user_authentication
